Darwins Robot Olympics is a physics based neuroevolution experiment I did a few years back. A population of robots equipped with neural networks are being trained to reach a specific target as fast as possible, often failing hilariously while they learn. Choose between robot worms, cars, starfish, and birds. Watch the robots go from limp vegetables to flying ninjas in just a few generations!

Try it out yourself right now: [linky](https://h4tt3n.github.io/darwins-robot-olympics/)

Darwins Robot Olympics is my attempt at exploring the machine learning topic neuroevolution and having a bit of fun at the same time. I wrote this project back in 2023 during a course on machine learning. The code was churned out during an intense two-week coding session. The project has been written entirely in plain JavaScript, with no external dependencies. The project is open-sourced, and code contributions are welcome.


## Introduction

When studying machine mearning, I noticed that neuroevolution - the combination of genetic algorithms and neural networks - has some very interesting properties. I wanted to dive in and explore! There already are quite a few online demos of neuroevolution, for instance a multitude of variations over the Genetic Cars theme, but I didn't think they quite captured how awe-inspiringly good this algorithm is. Most of them are also very similar and get boring to watch after a few generations.

I wanted to create something similar, but with more variation and emergent behavior. The result: Darwins Robot Olympics!

## How to "play"

Go to the Darwins Robot Olympics github page. Click "Start challenge!" to run the default simulation (worms learning to sprint towards the target, no obstacles). Optionally, you can start by selecting a challenge and robot from the dropdown menus, or maybe change the number of robots. That's it. Have fun!
